# Same Land, Unequal Tools

Interactive infographic for the 2026 NISR Infographic Competition.
Data: NISR, Seasonal Agricultural Survey 2025.

## Run it

1. Install Node.js (version 18 or newer) from https://nodejs.org
2. Open this folder in VS Code, then open the terminal (Ctrl + `)
3. Run:

   npm install
   npm run dev

4. Open the address it prints (usually http://localhost:5173)

## Edit it

- Numbers and text: src/App.jsx (the DATA and STATS blocks at the top)
- Colors and layout: src/index.css

## Build for hosting

npm run build   (output goes in the dist folder)
